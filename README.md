# LiteBrowser

Сверхлёгкий браузер для Android (APK ≈ 60 КБ) с блокировкой рекламы и скачиванием видео.
Использует системный WebView, без AndroidX и сторонних библиотек.

## Возможности

- **Блокировка рекламы**: запросы к рекламным доменам блокируются (список
  [Peter Lowe](https://pgl.yoyo.org/adservers/), ~3500 доменов, обновляется из меню),
  рекламные блоки скрываются через CSS, всплывающие окна запрещены.
- **Скачивание видео**: кнопка `⬇ N` показывает найденные на странице медиа.
  - Прямые файлы (mp4, webm, mkv, mp3…) скачиваются через системный DownloadManager.
  - HLS-потоки (`.m3u8`) выбирается лучшее качество, сегменты склеиваются, поддерживается AES-128.
    Загрузка идёт в фоне с уведомлением и кнопкой «Отмена».
  - Долгое нажатие на ссылку/картинку → «Скачать».
  - Файлы сохраняются в `Download/LiteBrowser`.
- Полноэкранное видео, поиск через DuckDuckGo, можно сделать браузером по умолчанию.

## Ограничения

- Видео с DRM (Netflix, SAMPLE-AES и т.п.) не скачивается.
- YouTube отдаёт видео через blob/MSE-потоки — их встроенный детектор не видит.
- HLS сохраняется как `.ts` (или `.mp4` для fMP4) — большинство плееров (VLC, MX) открывают его.

## Сборка

Требуется JDK 17 и Android SDK 34.

```sh
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # тесты HLS-загрузчика
```

Release подписан debug-ключом, чтобы APK сразу устанавливался. Для публикации в магазине
замените `signingConfig` на собственный ключ. Готовый APK также собирается в GitHub Actions
(артефакт `LiteBrowser-apk`).
